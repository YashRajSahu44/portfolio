# Portfolio 

A modern personal portfolio built with React, Vite, TanStack Router, and Tailwind-inspired styling. It showcases projects, skills, certifications, and experience in a clean, polished interface with motion-based interactions.

## Features

- Responsive single-page portfolio layout
- Project cards with looping demo videos
- Smooth motion transitions using Framer Motion / Motion
- Routing with TanStack Router
- Clean dark/light themed visual design
- GitHub contributions section integration

## Tech Stack

- React
- Vite
- JavaScript
- TanStack Router
- Tailwind CSS
- Motion
- Lucide React

## Project Structure

```bash
src/

  routes/
    index.jsx
    projects.jsx

    experience.jsx
    certifications.jsx
  styles.css
```

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

This project is designed to present work in a portfolio-style layout with project previews, social/project links, and a clean personal brand aesthetic.
